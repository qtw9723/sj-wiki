# 주식 모니터링 웹페이지 구현 대화 원본 요약 (2026-11-06)

출처: Claude 대화(채팅), 2026-11-06 오전~오후 KST. 정리본은 wiki/주식-모니터링-웹페이지.md.
※ 이 저장소는 공개(public)다. 투입 금액·보유 수량·평균 단가 등 개인 금융 수치, 증권사 API 키, 비밀번호·일회용 코드는 적지 않았다.

## 사용자 요구·확정 사항 (📄 사용자 구술, 시간순)
1. 안정지향형(S&P500 ETF)만 살 것이라 초단위로 기민할 필요는 없다. 미래에셋에서 거래하며, 미래에셋 API가 생기면 그때 고려하고 지금은 검색으로 확인한다.
2. 대신 일정 주기로 갱신되는 스케줄이 있어야 하고, 화면도 실시간에 가깝게 갱신되어야 한다.
3. 장중 시세 수집 페이지가 기본이고, 이번처럼 특별한 일이 있을 때 쓰는 "특별 관리" 보기가 있으면 좋겠다. 관련 뉴스도 실시간에 가깝게 모으고 싶다.
4. 한국투자증권 API 키를 발급받아 직접 입력했다(App Key, App Secret).
5. 비밀번호를 걸고, 개인 수치도 서버에 저장해 달라고 했다.
6. 뉴스 수집은 어디서 할지 골라 달라고 했다(네이버가 제일 좋은지 문의).
7. 선물은 안 봐도 되고 환율과 외국인 수급만 붙이고, VIX도 붙여 달라고 했다.
8. 각 시세가 보유 ETF에 주는 영향도와 호재·악재를 정리해 달라고 했다.
9. 작업 소스는 IdeaProjects 아래에 두고, 개인 깃에 올리고, 올린 형상이 배포되게 해 달라고 했다. sj-wiki에도 정리하라고 했다.
