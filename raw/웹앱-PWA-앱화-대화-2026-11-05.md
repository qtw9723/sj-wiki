# 웹 프로젝트 앱화(PWA) 상담 대화 원본 (2026-11-05)

출처: Claude 대화(채팅). 사용자 질문과 확정 조건만 보관. 답변 내용은 wiki/웹앱-PWA-앱화-가이드.md에 정리.

## 사용자 질문·확정 조건 (📄 사용자 구술)
1. 웹 기반 핸드폰 앱을 하나 만들고 싶다. 웹을 고치면 앱 화면도 자동으로 고쳐지는지 궁금하다.
2. WebView 방식으로 앱을 만들고 싶다. iOS에 공유하려면? **App Store 등록은 하지 않고** 하고 싶다.
3. 사용자 수는 많지 않고, 간단하게만 쓸 것이다. **앱 자체의 업데이트는 하지 않으려** 한다.
4. PWA가 일반 웹앱과 뭐가 다른지, 특별히 설정할 게 있는지 궁금하다.
5. 안드로이드는 어떻게 해야 하는지 궁금하다.
6. 위키에 "웹 프로젝트를 앱화하는 방법"으로 정리해 저장하고, 다른 개발자에게 이 방식으로 개발해보라고 카톡으로 전달할 용도로도 정리해 달라.

## 대화 결론 (🧠 Claude 답변 요약)
- 위 조건(App Store 미등록 + 소수 사용 + 앱 업데이트 안 함)에서는 WebView/TestFlight보다 PWA가 맞다.
- iOS는 Safari에서 "홈 화면에 추가", 안드로이드는 크롬 등에서 "앱 설치/홈 화면에 추가".
- 필요한 설정: manifest.json, 아이콘(180/192/512), 메타 태그, HTTPS, 모바일 반응형. 서비스 워커는 오프라인·푸시가 필요할 때만.
