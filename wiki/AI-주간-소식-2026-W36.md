> [!tip] 핵심 takeaway
> **에이전트 오케스트레이션이 실사용 단계에 진입했다.** KT의 에이전트 커넥터(챗봇·상담봇·AI 뱅커를 유기적으로 연결)와 심심이의 멀티에이전트 AI 카운슬러(평가→코치→세이프티 가드레일)는 sangjun이 만드는 챗봇 시나리오 툴 ([[CogInsight-Generator]])과 직결되는 설계 패턴이다.
> 앤트로픽이 AWS 서울 리전에 Sonnet5·Opus5를 배포 예정 → Claude API 국내 접근성 개선.
> 채용 트렌드: SK하이닉스가 면접장 PC에서 LLM으로 과제 푸는 방식 도입 → LLM 활용 능력이 곧 핵심 역량.

## 🔥 빅 이슈

### 앤트로픽 AWS 서울 리전 배포 예정 — Sonnet5·Opus5
📄 앤트로픽이 AWS 서울 리전에 Sonnet5, Opus5 등 최신 LLM을 선보이고 국내 엔터프라이즈 시장 공략 가속 예고. 오픈AI-커서 결별 이슈도 동시 보도.
([digitaltoday](https://www.digitaltoday.co.kr/news/articleView.html?idxno=696679))
🧠 국내 기업용 Claude API 레이턴시 개선 + 데이터 레지던시 요건 충족 → [[CogInsight-Generator]] 같은 국내 B2B SaaS에 Claude 채택 장벽이 낮아진다.

### KT 우리은행 '에이전틱 AICC' — 에이전트 커넥터
📄 KT가 '에이전트 커넥터(Agent Connector)' 솔루션으로 챗봇·상담봇·AI 뱅커·AI 에이전트를 유기적으로 연결하는 에이전틱 AICC 구축 계획 발표.
([ajunews](https://www.ajunews.com/view/20260831083833684))
🧠 다수의 전문화된 에이전트를 커넥터 레이어로 묶는 패턴 — 오케스트레이터가 라우팅을 담당하고 각 에이전트는 단일 책임을 갖는 구조. [[CogInsight-Generator]]의 시나리오 분기 설계에 직접 참고 가능.

### SK하이닉스 채용 — 면접장 PC에서 LLM으로 과제 해결
📄 SK하이닉스, 11월 면접에서 지원자가 면접장 PC에서 LLM으로 과제를 풀어야 하는 방식 도입. 구글코리아 보고서: 기업 핵심 인재 역량 1위 'AI 기반 도구 활용 능력' 35%.
([naver](https://n.news.naver.com/mnews/article/018/0006360598?sid=101))
🧠 LLM 활용 능력이 채용 기준으로 공식화되는 추세. [[내-프로필]]의 "LLM 활용 역량 축적" 방향과 일치 — 실무 포트폴리오 중요성 상승.

## 🤖 에이전트·멀티에이전트

### 심심이 멀티에이전트 AI 카운슬러 — 42억 국책과제
📄 심심이가 멀티에이전트 기반 AI 카운슬러 엔진 개발 역할로 42억 규모 양극성장애 디지털 치료기기 국책과제에 선정. 구성: **상태 평가 에이전트 + 코치 에이전트 + 세이프티 가드레일(Safety Harness) 에이전트** 오케스트레이션.
([naver](https://n.news.naver.com/mnews/article/092/0002435571?sid=105))
🧠 가드레일을 독립 에이전트로 분리하는 패턴은 멀티에이전트 시스템에서 안전성을 높이는 검증된 방식 — 에이전트 간 체크 구조로 참고.

### 바이낸스 에이전트 OS — Claude Code·MCP 서버 채택
📄 바이낸스가 AI 에이전트 통합 플랫폼 '에이전트 OS' 공개. ChatGPT, Cursor, Codex, **Claude Code** 등과 호환되는 MCP 서버 채택. 개발자가 자신의 AI 에이전트를 바이낸스 금융 인프라(시장 데이터 등)에 연결 가능.
([etoday](https://www.etoday.co.kr/news/view/2619778))
🧠 MCP가 금융 인프라 수준의 플랫폼에도 채택 → [[내-MCP-커넥터-환경]] 관점에서 MCP 표준화 가속 확인.

### X(트위터) 광고 캠페인 데이터 → ChatGPT·Claude·Grok에 개방
📄 X가 광고주의 ChatGPT, Claude, Grok 또는 자체 에이전트를 통해 캠페인 데이터를 직접 관리할 수 있도록 개방.
([wikitree](https://www.wikitree.co.kr/articles/1156060))
🧠 플랫폼 데이터를 AI 에이전트에 직접 연결하는 접근 — 향후 업무 자동화 툴에서 외부 서비스 데이터를 에이전트에 연결하는 패턴의 선례.

### 통신 3사 AI 에이전트 경쟁
📄 SKT — 개인용 AI 웨어러블 일상 기록 서비스. KT — 금융권 AI 상담 에이전트 시스템 구축. LGU+ — 도시 에너지 시설 안전관리 AI 에이전트 적용.
([newscj](https://www.newscj.com/news/articleView.html?idxno=3428845))
🧠 에이전트 AI가 B2C(웨어러블)·B2B(금융·인프라) 전 방위에 동시 확산 중. [[에이전트-자동화-도구]] 업데이트 필요.

### "챗봇을 넘어 AI 에이전트" — AX 시대 핵심 전략
📄 생성형 AI 도입으로 지식 생산 과정이 해체되고, 에이전트·전문 툴 결합 오케스트레이션 환경이 AX(AI Transformation) 핵심 전략으로 부상. 멀티플레이어 에이전트와 산업 자동화 플랫폼 설계·통제가 관건.
([naver](https://n.news.naver.com/mnews/article/092/0002435575?sid=110))

## 🌐 오픈소스·모델

### 아스테로모프 AI — 국제물리올림피아드 금메달 (오픈소스 모델만 사용)
📄 아스테로모프 AI, 국제물리올림피아드(IPhO)에서 28.6점 획득, 금메달 수준. GPT 같은 상용 모델 없이 **오픈소스 모델과 자체 AI 시스템만**으로 고난도 물리 문제 해결.

### 피지컬 AI / VLA 교육 확대 — 서울 AI 허브
📄 서울 AI 허브, VLA(Vision-Language-Action)·LLM 기반 로봇 지능·로보틱스 파운데이션 모델을 교육과정에 포함한 피지컬 AI 전문 인재 배출 프로그램 가속.

## 🛡️ 안전·규제

### 앤트로픽 저작권 소송 — 소니·워너 vs 앤트로픽
📄 소니뮤직·워너뮤직이 앤트로픽 상대로 소송. Claude에 특정 노래 가사를 묻자 원저작자 정보 없이 가사 전체가 복제 출력된 사례 근거. "역사상 가장 거대하고 노골적인" 저작권 침해 주장.
([naver](https://n.news.naver.com/mnews/article/021/0002814935?sid=104))
🧠 LLM 서비스에서 저작권 있는 콘텐츠(가사·소설 등) 그대로 출력하는 기능은 법적 리스크 → [[CogInsight-Generator]] 같은 콘텐츠 생성 도구에서 출력 필터링 고려 필요.

### AI 직종 노출 분석 — 변호사 1위, 30대 53%
📄 Claude 사용 데이터 + 지역별고용조사 연계 분석: AI 고노출 직종 1위 **변호사**. 30대 고용보험 가입자 53%가 AI 중·고노출 직종. ChatGPT 출시(2022 하반기) 전후 30세 미만 고용 변화 추적 필요.
([naver](https://n.news.naver.com/mnews/article/001/0016279373?sid=102))

### Claude 개인정보 보호 설정 가이드
📄 Claude '설정 > 개인정보 보호'에서 'Help improve Claude' 옵션을 끄면, 대화 삭제 후 30일 내 백엔드에서도 제거.
