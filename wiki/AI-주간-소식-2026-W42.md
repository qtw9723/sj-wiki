> W42 첫날 수집 신호 전체가 **에이전트 AI가 기업 표준으로 안착하는 과정**을 보여준다.

> 고립 에이전트 문제는 **지금 만드는 구조에 직접 반영할 설계 신호**다.

## 🔥 빅 이슈

### W42-01 — 에이전트 AI 기업 도입 33% → 68% 급성장 전망
📄 Automation Anywhere *"자율형 AI 에이전트 기업 도입률 33% → 68%로 급성장 전망"*(AI Global Forecast 인용). **2026년 에이전트가 주도하는 첫 주요 기업 워크플로는 소프트웨어 개발.**

🧠 "첫 워크플로 = 소프트웨어 개발"은 [[내-프로필]] *"비개발 → 개발 전환 중"* 타이밍과 맞물린다. 자동화 에이전트를 직접 다루는 [[mailer|CS SmartHub]]·[[CogInsight-Generator]] 포트폴리오가 이 흐름 위에 있다.

⚠ 📄 *"33% → 68%"* 원출처는 *AI Global Forecast*(Automation Anywhere 발간) — 자사 조사이므로 수치 인용 시 출처 명시.

### W42-02 — 기업 평균 12개 에이전트 운영, 절반은 고립
📄 Belitsoft 보고서(Futurum Group 설문 인용): *"기업 평균 12개 AI 에이전트 운영하지만 절반은 다른 에이전트와 연결 없이 독립 동작."* 자율 에이전트·Agentic AI를 최우선 기술 과제로 꼽는 응답 13% → 17.1% 증가.

🧠 **12개 에이전트가 연결 없이 돌아간다 = [[에이전트-자동화-도구]] §오케스트레이션 절에서 이미 다룬 갭이 수치로 확인됐다.** [[CogInsight-Generator]]의 에이전트 게이트(단일 에이전트 + 게이트) 설계 근거로 쓸 수 있다.

### W42-03 — 2026년 말 기업 앱 40%에 특화 에이전트 탑재 + 보안 위협 급증
📄 Belitsoft: *"2026년 말까지 기업 애플리케이션의 40%에 특화 에이전트 탑재 예상."* 📄 Google: *"기업용 AI를 겨냥한 표적형 프롬프트 인젝션 공격 급증 전망."* 📄 Forrester: *"에이전트 AI 데이터 유출 사고 공개 및 직원 해고 예측."*

🧠 프롬프트 인젝션 위협은 [[CogInsight-Generator]] LLM 호출 체인 보안 설계에 직결된다. 허용 동사 제한(→ [[내-프로필]] §성문화 4호 국방 사례)이 대응 방향.

## 🤖 에이전트·멀티에이전트

### W42-06 — 멀티에이전트 위협 3종: 연쇄 환각·충돌 교착·자원 과부하
📄 2026 싱가포르 AI 안전 연구 합의문(중국 TC260 에이전트 안전 표준 인용): *"멀티에이전트 시스템 위협으로 연쇄 환각 전파, 충돌 교착, 자원 과부하 지목."* 📄 Forrester: *"2027년까지 작업 중심 에이전트 악용 비용이 멀티에이전트 대비 최소 4배 예상."*

🧠 "연쇄 환각 전파"는 에이전트 간 출력을 검증 없이 넘기는 파이프라인에서 발생 — [[CogInsight-Generator]] 에이전트 체인 게이트 설계의 방어 대상.

### W42-07 — LLM 에이전트 설계가 2026년 표준으로
📄 wikidocs: *"LLM 응용 개발의 핵심으로 에이전트 설계가 표준화: 스스로 도구를 사용하고 웹 검색, 복잡한 문제 해결."* 2026년 LLM 개발 흐름 한국어 정리.

### W42-16 — Gartner·Forrester·IDC "2026년 = 에이전트 AI의 해"
📄 주요 분석기관들이 2026년을 에이전트 AI의 해로 규정. 📄 Cisco, Microsoft는 '연결된 지능(Connected Intelligence)' 시대로 명명. 📄 *"2026년 에이전트가 며칠~몇 시간 작업을 독립 수행하는 단계로 진입."*
