## 데모에 구현된 기능 (📄)

- **라이브러리(검색·분류)**: 곡명·작곡가·가사 검색 + 조성·절기·난이도 필터, 곡 카드/상세.
- **업로드**: 드래그&드롭 + 메타 입력 + 중복 감지(목업).
- **곡 버전 선택**: 곡마다 여러 편곡/조성 버전(팀 편곡·낮춘 키·원본) → 콘티에 담을 때 골라서.
- **콘티(인도자 화면, "콘티 만들기")**: 주일 1·2부·수요·금요 **여러 콘티 동시**, 곡 순서·조성, 검색·"지난 예배 접기".
- **콘티 3상태**: `준비중 → 공개 → 완료`. 준비중=팀원 숨김 / 공개=팀원 노출 / 완료=지난 예배(맨 아래 정렬). — 🧠 원래 D-결정엔 없던, 데모에서 다듬은 라이프사이클.
- **라인업(포지션별 담당자)**: 보컬·건반·스트링·리듬·총괄 5그룹, 가변(싱어 다수·악기 구성 변화 대응) + 팀원 포지션 메모.
- **송폼·공용 메모**: 인도자가 곡별 송폼(Intro–V1–C…)·공지 작성 → 팀원 찬양모드 상단 러닝헤더로 표시(= D4 "송폼은 공용 메모로"의 구현).
- **팀원 화면(열람 전용)**: 공개된 콘티만, 다가오는 예배 위·지난 예배 접힘, 예배 콘티(순서·조성·버전·악보).
- **찬양모드(실전 리더)**: 콘티 전곡 악보를 하나로 **이어 스크롤** + 악보 위 **펜 필기**(펜/형광/지우개·5색·필압). — D1·D2·D7 구현.
- **역할 전환 홈**: 인도자/팀원 대시보드 스위치(라이브 데이터 기반).
- **반응형**: PC·태블릿·모바일. 모바일은 **하단 탭바**로 내비게이션, 2단 레이아웃 세로 스택.
- **찬양모드 펜/터치 구분(태블릿)**: 기본 **펜=필기 / 손가락=스크롤**(`touch-action:pan-y`), "손가락 필기" 토글로 손가락 필기 허용. — [[악보-아카이브-필기-크로스플랫폼]]의 팜 리젝션 개념을 데모에 반영.

## 제안서(PPT/PDF) 구성 (📄 10슬라이드)

표지(이름 뜻풀이) → 현실 As-Is(악보가 흩어져 있음) → 제안 To-Be(모으고 찾고/예배 준비/예배 현장) → **핵심기능 3막** → **찬양모드 스포트라이트**(전곡 이어보기+애플펜슬 메모) → 데모 미리보기 → 기대효과(Before/After) → 도입 로드맵(SJP 파일럿→정착→다른 팀 확대) → 비용·운영 → 다음 한 걸음.

- 🧠 **개발 기한은 명시하지 않음**(사용자 요청 — "가볍게 시작/팀의 기본으로/필요할 때·선택"으로 표현).
- 📄 제안자 = **박상준**(인도자 직함 뺌), 대상 = SJP 찬양팀 리더.
