## 문제 📄
- 로비 LED 화면에서 **100문제를 돌아가며 푸는 협동 탈출게임**. 어떤 노트북에서든 주소만 열면 돌아가야 한다(README).

## 내 역할
- 📄 저장소에 역할 명시 **없음**. 🧠 사용자 확정(전부 개인 프로젝트)으로 기획·구현·배포 전체로 본다.

## 기능 📄 (README)
- **LED 화면** `/`(전체화면용, 10초마다 상태 확인) / **백오피스** `/admin`(앱 비밀번호 보호).
- 문제 유형: 주관식(정답 여러 개) / 객관식(보기 2~6개), 이미지 선택(브라우저에서 1600px 이하로 줄여 업로드, 3MB 제한).
- 100문제 관리: 검색·필터, 드래그/▲▼ 순서 변경, 선택 활성·비활성·삭제, 일괄 등록, JSON 백업.
- ▶ 표시로 해당 문제를 LED에 즉시 띄움(최대 10초 내 반영), 진행 초기화(풀이 기록만 삭제).
- 정답 비교는 띄어쓰기·대소문자 무시, **정답 판정은 서버에서만**.

## 기술 📄
- Vercel(함수 진입점 `api/[...path].js`, 도쿄 리전) + Supabase(`@supabase/supabase-js`) + 순수 정적 HTML(`public/index.html`, `admin.html`). Node 22.
- DB: `ledquiz_questions`, `ledquiz_state`, 정렬 함수 `ledquiz_reorder`, 공개 이미지 버킷. **기존 테이블과 겹치지 않게 모두 `ledquiz_` 접두어**, RLS 켜고 서버(서비스 키)만 접근 → 🧠 [[parking]]이 쓰는 같은 Supabase 프로젝트를 공유하기 때문.
- 테스트: `test/`(가짜 Supabase 하네스, `node test/run.js`, 배포 제외). 규모 약 1,400줄(app.js 444 · admin 618 · index 321).
