> [!tip] 핵심 takeaway
> 서킷브레이커 당일 대화에서 시작해 **하루 만에 "수집 → 저장 → 비밀번호 대시보드"까지 돌아가는 개인 투자 보조 도구**가 됐다. 이 ETF(TIGER 미국S&P500)에 직접적인 것은 **미국 지수·환율·괴리율**이라, 화면도 그 값들을 앞에 둔다.
> 개발자 관점에서 재사용할 부분은 **"5분 pg_cron → Edge Function 수집 → RLS 잠근 DB → 토큰 인증 API → 정적 페이지"** 구조다. [[mailer]]의 pg_cron 수집 패턴과 같은 계열이라 그대로 가져다 쓸 수 있다.

> [!warning] 투자 권유가 아니다
> 화면의 "충족한 기준"은 사용자가 정한 조건을 얼마나 채웠는지만 보여 준다. 매수 신호가 아니다. 개인 금융 수치(투입 금액·보유 수량·평균 단가)는 공개 저장소라 이 페이지에 적지 않았다. 해당 값은 DB의 설정 테이블에만 있다.

## 1. 무엇을 하나 (📄 사용자 요구 기준)
- 📄 장중 시세를 일정 주기로 수집해 화면에 거의 실시간으로 보여 준다.
- 📄 코스피가 크게 빠진 날처럼 특별한 날을 위한 "특별 관리 모드"(배너)가 있다.
- 📄 뉴스를 실시간에 가깝게 모은다.
- 📄 비밀번호를 걸고, 개인 설정은 서버에 저장한다.
- 📄 환율·VIX·외국인 수급을 자동으로 붙이고, 선물은 제외한다.

## 2. 구조 (📄 이 세션에서 구현·확인한 것)
```
한국투자증권 Open API ─┐
Google News RSS ──────┤  Supabase pg_cron (5분)
                      ▼
 Edge Functions: collect / news-collect ─▶ Postgres (quotes, flows, news …, RLS만 켜고 정책 없음)
                                                │
 Edge Function: app-api (비밀번호 로그인 + 토큰) ◀┘
                      ▲
        정적 HTML 한 장 (Vercel, 30초 폴링)
```
| 구성 | 내용 |
|---|---|
| 수집 | 한투 API로 ETF 현재가·iNAV·괴리율, 코스피, S&P500 지수, 원/달러, VIX, 코스피 투자자별 수급. 5분마다. 장 시간대(krx/us/always)에 따라 항목별 수집 여부 결정 |
| 뉴스 | 구글 뉴스 RSS, 한국어 5개·영어 2개 검색어. URL 중복 제거, 48시간 이내만 |
| 인증 | 비밀번호는 PBKDF2-SHA256(10만 회) 해시. 세션은 HMAC 토큰 30일. 15분에 8회 실패 시 잠금. 최초 설정은 일회용 코드 |
| 화면 | 현재 시세 카드, 지표별 영향 표, 뉴스, 기준 판정(5개), 추이 그래프, 내 보유, 분할 매수 플래너, 한 번에 vs 나눠서, 환율 민감도 |

## 3. 지표가 이 ETF에 주는 영향 (🧠 일반적 관계에 기반한 판단)
| 지표 | 영향도 | 보유분 기준 방향 |
|---|---|---|
| S&P500 지수·선물 | 매우 큼 | 오르면 호재, 내리면 악재 |
| 원/달러 환율 | 큼 | 환노출형이라 환율 오르면(원화 약세) 호재, 내리면 악재. 환율 1% ≈ ETF 약 1% |
| VIX | 간접 | 오르면 악재 신호, 내리면 호재 신호 |
| 괴리율 | 작음 | 보유 평가보다 **살 때** 영향. 플러스가 크면 불리 |
| 코스피·외국인 수급 | 거의 없음 | 중립. 환율을 거쳐서만 간접 영향 |
- 🧠 추가 매수 관점에서는 해석이 달라진다. 하락은 보유분엔 악재지만 싸게 살 기회이기도 하고 더 내릴 위험도 있다.
- 이 표는 대시보드의 "지표별 영향" 섹션에 현재 값과 함께 자동 표시된다.

## 4. 확인된 것과 아직 검증 못 한 것
- 📄 한투 API로 ETF·코스피·S&P500·환율·VIX 값이 실제로 들어오는 것을 호출 결과로 확인했다.
- ⚠ **외국인 수급 단위**: 원본이 거래대금(pbmn)이라 백만원으로 추정해 억원으로 환산해 표시한다. 문서로 확인하지 못했다. 증권사 앱 값과 대조 필요.
- ⚠ 외국인 순매수 **수량은 음수인데 금액은 양수**로 나온 시점이 있었다. 종목별 단가 차이로 가능하다고 보지만 확정하지 못했다.
- ⚠ 환율·VIX는 **일별 시세 조회**라 장중 실시간과 차이가 날 수 있다. 환율 전일 종가도 이 세션의 검색 값과 달랐다(한투 값을 채택).
- ⚠ 미국 지수는 미국장이 닫혀 있으면 직전 종가다.
- ⚠ 구글 뉴스 RSS의 제목은 요약일 뿐이고 사실 확인은 본문에서 해야 한다. 네이버 검색 API는 키 입력이 막혀 못 붙였다(후보).
- 🧠 선물은 한투 해외선물 API가 별도 계좌를 요구해 보여서 제외한 결정을 따랐다(사용자 확정).

## 5. 소스 위치와 배포 (현재 상태)
- 📄 로컬 소스: `IdeaProjects/market-board` (웹 `web/`, 함수 `supabase/functions/`, SQL `supabase/sql/`).
- 📄 배포: 화면은 Vercel, 함수·DB·수집 스케줄은 Supabase. 주소와 프로젝트 식별자는 공개 저장소라 적지 않았다.
- 📄 개인 깃: GitHub 비공개 저장소 `qtw9723/market-board`에 푸시했다(2026-11-06). 화면은 Vercel 프로젝트를 이 저장소(루트 `web/`)에 연결해 **`main` 푸시 시 자동 배포**된다.
- 📄 함수 배포: `supabase/functions/**`가 바뀌면 GitHub Actions가 배포하도록 워크플로를 넣었다. 단 저장소 시크릿(Supabase 액세스 토큰·프로젝트 ref)을 넣기 전에는 건너뛴다. 수동 배포는 `scripts/deploy-functions.sh`.
- ⚠ 새 Vercel 프로젝트는 기본으로 Vercel 로그인 보호가 켜져 있다. 앱 자체 비밀번호가 있으므로 끄는 것은 사용자가 설정에서 결정한다.
